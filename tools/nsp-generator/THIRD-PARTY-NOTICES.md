the `@tootallnate/hacbrewpack` / `@tootallnate/nacp` packages from
[TooTallNate/switch-tools](https://github.com/TooTallNate/switch-tools).

The forwarder template resources are obtained from that project's
`apps/nsp-forwarder/public/template` directory. The upstream project credits
RetroArchROMForwarder, hacBrewPack, NSP-Forwarder and Forwarder-Mod.

MFG does not ship, collect or transmit Switch key material. The user's key is
decrypted only for the local generator process and is written to a random
temporary directory that is deleted once generation finishes.
