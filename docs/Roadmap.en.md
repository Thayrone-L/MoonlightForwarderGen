# Roadmap

[Português](Roadmap.md) | **English**

## Delivered in the current alpha

- WPF Companion with a visual library.
- Steam, Epic, and local executable discovery.
- Sunshine installation, configuration, and health checks.
- Resumable onboarding.
- Persistent language selection and onboarding in Portuguese and English.
- Protected `prod.keys` storage.
- NSP forwarders with title, cover, and unique Title ID.
- Verified SD card synchronization.
- Graphical MFG Updater with HOME menu installation.
- Initial tests, CI, and automated release pipeline.

## Next alpha releases

1. Expand unit tests for services and manifest contracts.
2. Complete localization of the main screen, service messages, and MFG Updater.
3. Improve recovery messages and in-app diagnostics.
4. Validate the full flow across Windows, Sunshine, and Moonlight-Switch versions.
5. Add local-only timing and failure diagnostics, with no external transmission.
6. Implement opt-in forwarder removal in MFG Updater.

## Before beta

- Windows installer with clean uninstallation;
- code signing or formal checksum documentation;
- explicit database and configuration migrations;
- generator and SD card integration tests;
- a visual guide with screenshots and a short video;
- a public hardware compatibility matrix.

## Later ideas

- GOG, Playnite, and Xbox libraries;
- automatic Companion updates;
- Wake-on-LAN;
- game-session start and shutdown automation.
