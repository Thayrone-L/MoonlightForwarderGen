# Template NSP

**Português** | [English](README.en.md)

Coloque aqui o template NSP compatível com o backend de geração escolhido.

O MFG trata esse arquivo como uma entrada de geração. Ele não altera um NSP pronto diretamente: cada jogo precisa de um novo pacote construído com Title ID, metadados e argumentos do Moonlight próprios.
