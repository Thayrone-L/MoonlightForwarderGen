# Contributing

[Português](CONTRIBUTING.md) | **English**

Thank you for your interest in Moonlight Forwarder Generator.

## Before contributing

- For bugs, open an issue with the version, environment, steps, and observed message.
- For larger changes, first describe the proposal and its impact on the user flow.
- Never attach `prod.keys`, personal databases, credentials, or unreviewed logs.

## Set up the environment

See [docs/Development.en.md](docs/Development.en.md) for dependencies, build, tests, and packaging.

## Change criteria

- build without new warnings;
- maintain or expand relevant tests;
- preserve settings external to MFG;
- present errors in useful language;
- update README, architecture, or contracts when behavior changes;
- keep sensitive data out of code, fixtures, and logs.

## Pull requests

Explain the problem, the chosen approach, and how the change was validated. Include an image or short video for visual changes. For Sunshine, Moonlight, or SD integrations, also describe the recovery path when the dependency is unavailable.
